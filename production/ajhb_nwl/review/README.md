# AJHB review workspace

Use this folder for:

- `reviewer_comments.md` — verbatim editor/reviewer comments
- `revision_checklist.md` — working checklist and status
- `response_to_reviewers.docx` — final point-by-point response document

Reviewer-specific analyses should be implemented transparently in the production codebase, preferably in `R/09_reviewer_revision.R` unless they become part of the permanent main-analysis pipeline.
